# Backlog

Offene Vorhaben stehen als Issues auf GitHub:
<https://github.com/worstcasebc/C64-DE25/issues>

- Label `feature-request`: neue Funktionen (z. B. Formatieren und `.G64`,
  WLAN, Gamepads, Absicherung des Dienstes auf dem Board)
- Label `clean-up`: Aufräumarbeiten und noch nicht Ausprobiertes

Ein Commit, der ein Vorhaben abschließt, nennt es in der Nachricht
(`Fixes #<Nummer>`); GitHub schließt das Issue dann beim Push.
